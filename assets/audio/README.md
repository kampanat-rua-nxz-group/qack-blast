# Sound assets

All eight sounds are original and generated by `tools/generate_sounds.gd` from plain math (sine and triangle tones plus seeded noise). No recordings, samples, or third-party assets are used, so there is nothing to license or attribute.

| File | Cue |
| --- | --- |
| `place.wav` | bomb placed |
| `explode.wav` | bomb exploded |
| `pickup.wav` | pickup collected |
| `eliminate.wav` | a duck is eliminated |
| `countdown.wav` | round countdown tick |
| `win.wav` | you won the round |
| `loss.wav` | you lost the round |
| `draw.wav` | the round was a draw |

Regenerate them (output is deterministic) from the project root:

```sh
/Applications/Godot.app/Contents/MacOS/Godot --headless --path . --script tools/generate_sounds.gd
```
